Static vs Dynamic Summary
Always Static (Design Only)
  • Static Blue Section Banner styling (#1f497d)
  • Static Black Banner styling (#404040)
  • Static Table header colors & fonts
  • Static Table border color (#1f497d)
  • Static A4 page dimensions
  • Static Bullet point indent & style
  • Static Font family (Cambria)
  • Static Color palette (all hex values)
  • Static End of Report marker style

  • Dynamic Patient name, age, gender
  • Dynamic Sample ID, dates, lab ID
  • Dynamic Report title text
  • Dynamic Clinical indication text
  • Dynamic Variant table rows
  • Dynamic Interpretation paragraphs
  • Dynamic Footnotes & warning notes
